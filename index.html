The Bay Model

#30DayMapChallenge: Borgesian Map

The Bay Model is a massive indoor 1:1000 scale model of the San Francisco Bay and its adjacent waters, built by the U.S. Army Corps of Engineers. It is now an educational center, open to the public.

The sheer size of the model is staggering. It fills an entire warehouse, and you can walk around inside.

Because the model is focussed on hydrology, the land portions of the model are absent or (almost) completely undetailed, although there are a few cute scale models of features on land like Alcatraz, or the Golden Gate Bridge. Pondering these not-so-tiny scale models, I found myself wondering, "What if the Bay Model had a Bay Model in it...?"

This infinitely zooming map is an answer to that question.

Note 1: you may notice that the California Delta part of the model doesn't line up correctly. That's a real quirk of the model: to fit the model inside the building, they added an extra bend at Carquinez Strait.

Note 2: I added the Bay Model outline to OpenStreetMap as part of this project, estimating the shape based on the map in the Visitors Guide PDF available online, and aligning it to OpenStreetMap users' GPS tracks from inside the building. If you visit the Bay Model anytime soon, please check my work!

Note 3: When I mapped the shape into OSM, I was pleased to find that (if I did my mapping correctly) the model was built such that north in the model is aligned with true north. There's no reason for them to have built it that way, but it certainly makes this app simpler: no rotation required!
